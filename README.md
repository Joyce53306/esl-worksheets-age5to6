# ESL 學習單生成器（5-6 歲）

給 5-6 歲幼兒英語學習者的進階練習單，**需要基礎認字能力**，共 9 種：

1. **字母配對練習單** — 大寫配小寫，或字母配單字，畫線連連看
2. **Sight Words 練習單** — 描寫＋「圈出正確單字」練習
3. **字首音練習** — 看圖三選一圈出正確的開頭字母（Phonics）
4. **圖片單字配對** — 看 emoji 圖，三選一圈出正確單字
5. **單字拼圖 Word Search** — 自動排版字母格，可調整是否允許斜線／反向
6. **句型填空練習單** — 自訂句型（用 `___` 代表空格）＋單字庫
7. **介係詞練習** — in/on/under 情境圖，三選一圈出正確介係詞
8. **單複數練習** — 單數/複數（+s）對照描寫，結合數字與單字
9. **身體部位標示** — 人體圖編號對應單字庫，孩子填寫身體部位名稱

只有兩個檔案：`index.html`、`modules.js`，不需要任何後端或資料庫。

> 這是「學習單」系列中專給 **5-6 歲** 設計的版本。4 歲不太需要認字的類型（圖片配對、數字與單字、著色等），請看另一個 repo：**ESL 學習單生成器（4 歲）**。教具／課堂互動遊戲請看 **ESL 教具生成器**。

## 上架 GitHub 完整步驟

1. 登入 [github.com](https://github.com)
2. 右上角 `+` → `New repository`，取個名字（例如 `esl-worksheets-age5to6`），設為 **Public**
3. 點 `Add file` → `Upload files`，把 `index.html` 和 `modules.js` 一起拖進去 → `Commit changes`
4. 進 `Settings` → `Pages` → Branch 選 `main`，資料夾選 `/ (root)` → `Save`
5. 等 1-2 分鐘，會拿到網址：`https://你的帳號.github.io/esl-worksheets-age5to6/`

## 使用小提醒

- **列印**：每個學習單右上角有「列印」按鈕，只印練習單本體，版面已抓好 A4 邊界
- **單字拼圖**：單字多或長時記得把格子調大（例如 12-14）
- **圖片單字配對 / 字首音練習**：都需要 `單字:emoji` 格式才能顯示圖案，選項每次會重新打散
- **介係詞練習**：格式 `物品:emoji`，每次會隨機決定 in/on/under 其中一個並畫出情境圖
- **單複數練習**：格式 `單字:emoji`，複數會自動加 s（不完全處理不規則複數，如 mouse→mice 需自行手動調整）
- **身體部位標示**：固定六個部位（Head/Arm/Hand/Tummy/Leg/Foot），不需輸入內容，直接產生
